# Security Policy

This repository holds documents (Markdown and a logo), not running software. A security problem here is most likely a leaked secret, a personal data exposure, or a link that points to something unsafe.

## How to report a problem

Please do not open a public issue or a pull request for a security problem.

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe what you found and where (file and line, if you can).

The report is visible only to the maintainers. This repository publishes no e-mail address for security reports.

## What to expect

- We will read your report and answer through the same private form.
- We will say whether we accept it as a problem and what we plan to do.
- We ask you to keep the details private until the problem is fixed.

This is a small project. We cannot promise a fixed response time.

## Supported versions

Only the current content on the `main` branch is maintained.
